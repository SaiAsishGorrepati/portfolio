# Sai Asish — Portfolio

A responsive, static portfolio for Gorrepati Sai Asish, built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No package installation or build step is required. The typefaces load from Google Fonts when an internet connection is available; system fallbacks are included.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — visual system, responsive layouts, and motion
- `script.js` — theme, mobile navigation, skill filters, project notes, and scroll behavior
- `assets/sai-asish-portrait.jpeg` — hero portrait
- `assets/saiasishgorrepati_resume.pdf` — resume opened from the navigation bar


## Content notes

Project details, education, skills, certifications, and contact links are based on the supplied portfolio specification. Project metrics are presented as reported results. Repository links, certificate verification links, and a resume download are omitted because no direct URLs or resume file were supplied.

To publish, upload this folder to a static host such as GitHub Pages, Cloudflare Pages, Netlify, or Vercel.
